Senior QA Automation Engineer | AI & Test Architecture Lead

An editorial, Neubrutalist portfolio website inspired by Swiss typography and minimal framed app architecture.

## Features
- **Editorial Neubrutalist Design:** Warm linen canvas (`#EDEAE3`), dark forest slate ink (`#2A4A44`), framed viewport borders, and solid offset hover shadows.
- **Client-Side View Routing:** Seamless navigation between Home, Projects, About, and Resume tabs with animated progress bar and hash synchronization.
- **Filterable Projects Showcase:** 6 enterprise production projects across AI Architecture, Mobile Native, and Fintech.
- **Synchronized 3-Page Executive Resume:** Print-ready and downloadable PDF.
